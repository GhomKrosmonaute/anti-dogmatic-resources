Données ouvertes

Toutes les vérifications sont lisibles par programme, sous licence CC BY 4.0 : une API JSON statique, en lecture seule, sans clé ni inscription. Elle est servie avec Access-Control-Allow-Origin: *, donc lisible depuis n'importe quel site, dans le navigateur. Les données sont mises à jour à chaque publication et au plus toutes les dix minutes en cache.

API JSON (v2)

  • api/v2/index.json — version, date de génération, effectifs et adresses de tout le reste
  • api/v2/videos.json — les 50 vérifications les plus récentes, avec la liste des pages
  • api/v2/videos/page-{n}.json — les vérifications par pages de 50, avec les liens précédent et suivant
  • api/v2/videos/{id}.json — une vérification complète : affirmation, verdict, faits et sources, relecture, vidéo examinée, vidéos citées, Shorts, corrections
  • api/v2/rubrics.json — les cinq rubriques de la chaîne, avec leur nombre de vidéos
  • api/v2/rubrics/{id}.json — une rubrique et ses vidéos
  • api/v2/techniques.json — les techniques de manipulation
  • api/v2/techniques/{id}.json — une technique, les vidéos qui l'enseignent et celles qui en montrent un exemple
  • api/v2/channels.json — les chaînes dont des vidéos ont reçu une réponse
  • api/v2/channels/{id}.json — une chaîne, les vidéos examinées et les réponses publiées
  • api/v2/corrections.json — toutes les corrections, de la plus récente à la plus ancienne
  • data/claims.json — tout en un seul fichier, avec les mêmes fiches

Une vidéo

  • id — son identifiant, celui de son adresse
  • format — video (format long) ou short
  • publishedAt — date de publication, ISO 8601 en UTC ; durationSeconds : sa durée
  • rubric — sa rubrique : esprit-critique, religions, philosophie, pseudo-sciences ou systeme
  • claim — l'affirmation examinée et son verdict (faux, trompeur, non_demontre, inverifiable, exact), ou null pour une vidéo qui enseigne une technique (technique)
  • techniques — les techniques de manipulation sur lesquelles l'affirmation s'appuie
  • answers — la vidéo YouTube à laquelle elle répond, ou null ; series : sa partie dans une série de Shorts
  • facts — dans la fiche complète : les faits vérifiés et leurs sources ; review : comment le script a été relu ; references, next, shorts : les vidéos citées, celle que propose son écran de fin, les Shorts qui en sont tirés ; corrections
  • links — l'adresse de sa page et de sa fiche ; youtube : son identifiant, son adresse et sa miniature

Les adresses sont absolues. La forme de la v2 ne change pas : des champs peuvent s'ajouter, ignorez ceux que vous ne connaissez pas ; un changement incompatible ira dans api/v3/.

const api = 'https://ghomkrosmonaute.github.io/anti-dogmatic-resources/api/v2/';
const { items } = await (await fetch(api + 'videos.json')).json();
const faux = items.filter(video => video.claim?.verdict === 'faux');
